This folder contains program files written covering fundamental types in C++: integers, characters, floating point numbers, void, boolean, byte and size_t.

- Integers.
int type stores whole numbers; numbers without fractions.
Int take 4 types:
1. short integers::2::%h(u)(d)
2. integers::4::%(d)(u)
3. long integers::8::%l(u)(d)
4. long long integers::8::%ll(u)(d)

-Unsigned must be non-negative.
-signed can either be negative or positive.

- A string literal is a hardcoded value in a program. Integers have these literal representations:
1. binary: 0b
2. Octal: 0
3. decimal: default;
4. hexadecimal: 0x

-String literals can contain any number of single quotes for readability i.e:
1000000 == 1'000'000

To print octal and hexadecimal numbers, use: %x and %o respectively.
